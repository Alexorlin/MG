# Програмний модуль електронного підпису для системи електронного документообігу

Клієнт-серверний програмний комплекс накладання та верифікації електронного цифрового підпису з підтримкою локальної інфраструктури відкритих ключів (PKI), служби позначок часу та криптографічного аудиту цілісності бази даних.

## Основні функціональні можливості

- **Мульти-алгоритмічне криптографічне ядро:** підтримка схем `Ed25519` (RFC 8032), `ECDSA` (NIST P-256) та `RSA-2048 / RSA-4096` (PSS + SHA-256).
- **Захист особистих ключів:** збереження приватних ключів у контейнерах `PKCS#8` із симетричним шифруванням `AES-256-CBC` за PIN-кодом.
- **Локальний Центр сертифікації (Root CA):** випуск та валідація сертифікатів `X.509 v3`, адміністративне відкликання та генерація списків `CRL` (RFC 5280).
- **Служба позначок часу (TSA):** формування та перевірка криптографічних штампів часу UTC за моделлю `RFC 3161`.
- **Колективний мультипідпис:** централізоване багатостороннє погодження документів із контролем доступу за білими списками підписантів (`ACL`).
- **Аудит цілісності реєстру:** захист записів у СКБД PostgreSQL за допомогою незмінного геш-ланцюга `SHA-256 Hash Chain`.

## Структура репозиторію

- `EDS_Project.exe` — зібраний автономний виконуваний файл клієнтського графічного додатку для ОС Windows.
- `eds_project/client_app/` — вихідний код клієнтського додатку (`CustomTkinter`, криптографічне ядро, робота з ключами та контейнерами).
- `eds_project/server_api/` — серверна частина системи (`FastAPI`, `SQLAlchemy`, PostgreSQL/SQLite, модулі Root CA, TSA та аудиту).
- `eds_project/benchmark_crypto.py` — модуль експериментального тестування швидкодії криптографічних алгоритмів.
- `eds_project/build_exe.py`, `eds_project/main.spec` — скрипти збирання виконуваного файлу клієнта (`PyInstaller`).
